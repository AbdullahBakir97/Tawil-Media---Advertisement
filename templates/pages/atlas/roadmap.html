Architecture

1 · Vite build

Replace the Tailwind CLI with Vite: one bundle for CSS and JS, hashed filenames, code splitting, dev server with hot reload, and a manifest Django reads. Alpine and GSAP tree-shaken.

2 · App-like navigation

HTMX boost for every internal link and the View Transitions API for shared-element moves: a card cover grows into the article header, the page never flashes white. Pages stay server-rendered and indexable.

3 · Vue islands

Vue 3 mounted only where a widget needs real state: the campaign planner, the magazine reader, the command palette. Props come from a JSON script tag rendered by Django; the rest of the page stays plain HTML.
